# DevTree

A LinkTree clone where users create an account and share all their social media links from a single, customizable page.

## Tech Stack

- **Backend:** Node.js, Express, MongoDB, TypeScript
- **Frontend:** React (Vite), TypeScript, Tailwind CSS, React Query

## Features (planned)

- User registration and authentication
- Profile customization
- Add and manage social media links
- Image upload for profile pictures
